## Fixes made during the audit

- **Demo buttons below the fold sent people to sign-in**: Scrolling to the bottom "Start the demo" button brought the footer's Chat link into view; Next.js prefetched /chat while logged out and cached the sign-in redirect, which the button then replayed. Demo buttons now do a full navigation after the demo session starts.
- **Conversations couldn't be renamed**: Added an options menu per conversation (Rename / Delete), a rename dialog with a saving state, and PATCH /conversations/{id} (titles are redacted like everything else stored).
- **Keyboard focus was lost when the rename/delete dialogs opened**: The dialog opened while the menu was still closing, and the menu took focus back, leaving keyboard users on the page body. Dialogs now open after the menu has closed, so focus lands in the Name field / on the confirm buttons.
- **"New chat" on an empty chat and clicking the open conversation did nothing**: Both now put the cursor in the message box (and close the drawer on mobile).
- **A used-up demo only showed a disabled box after a reload**: "Demo complete. Create a free account to keep chatting" now shows whenever the demo is used up, not only right after the last message.
- **Back after signing in showed the sign-in form again**: The proxy sends signed-in people from /login straight on to where they were going (demo users can still reach it to create an account).
- **Back after signing out could show a private page, and sign-out signed out every device**: Sign-out is now for this browser only and replaces the history entry with a full navigation; private pages are sent with Cache-Control: no-store so Back re-checks the session and goes to sign-in.
- **Deleting a conversation had no working state**: The confirm button shows a spinner and both buttons are disabled until the delete finishes.
- **Pricing buttons didn't say what happens next**: Each plan button now has a note: "Email sign-in link. No card needed." or "Opens a short form. No payment." (no checkout exists).
- **The mood slider had no accessible name**: The slider thumb is now labelled "Mood, 1 to 10" and reads its value as "N out of 10, <word>".
- **Admin tab text was below contrast on dark**: Inactive tab text raised from 60% to 80% opacity (axe colour-contrast now passes in light and dark).
- **The admin top bar scrolled sideways at 390 px**: The logo text hides below the small breakpoint, so the bar fits on phones.
- **An ended session showed an error instead of sign-in**: A 401 from the API now signs this browser out once and goes to /login?expired=1 with "Your session ended"; links to private pages no longer prefetch (a prefetched sign-in redirect 404'd). In the audit, the reset now leaves the page (about:blank) before swapping cookies, so a stale /chat page can't fire that 401 during the next check.
- **Pricing claimed a BAA for the clinic plan**: The Clinic plan is now Teams ("for workplaces and community groups"), and the BAA line is "Custom onboarding and admin controls". Nothing on the site says HIPAA compliant.
- **The first write after the API woke up hung**: Found by the live specs: a mood note, rename or chat message right after a cold start waited on the redaction model's lazy load while /health already said ok. The API now loads it during warm-up, and /health reports a "redaction" check.
- **Live demo tests leaked anonymous users**: The demo button navigates as soon as sign-up returns, so the test never saw the new user's id. The test now passes the real sign-up through tagged as a test user and reads the id itself, so cleanup always finds it.
